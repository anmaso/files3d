# files3d

A file system navigator drawn as a building in isometric 3D. Each folder is a floor plan; opening a subfolder (a room) builds its floor on top, and the parent floors stay visible underneath.

## Concepts

`concepts/floor-concepts.html` is an interactive concept sheet with three stacking variants (stacked plates, light well, exploded section) running on a sample project tree. Open it in a browser; click rooms to go up, click lower floors or press Esc to go back down.
